Featured project

Loan Approval System

A Python application backed by a MySQL database, built as my Class 12 board project. It takes applicant details, checks them against a defined set of rules, shows the estimated monthly EMI, and keeps user accounts in the MySQL database.

Project details

Problem

Loan decisions made by hand are slow and easy to get wrong, and the reasoning disappears once the paperwork is filed.

Approach

Write the eligibility rules out first, turn them into Python functions, then store applicants and outcomes in linked MySQL tables.

Technologies

Python for the logic and interface, MySQL for storage, and SQL queries to retrieve and update records.

What I learned

Design the tables before the code. Handle the inputs you didn't expect. A working program and a reliable one are different things.

PythonRules & logic
ApplicationInput & decision
MySQLRecords & queries

Data flow: the Python layer applies the rules, the application handles input and output, and MySQL keeps every record queryable.

How it came together

Project breakdown

  1. Planning

    Listed what the system had to decide and wrote the eligibility rules in plain language before opening an editor.

  2. Development

    Built the Python logic in small pieces, testing each rule on its own before joining them together.

  3. Database

    Designed the MySQL tables for applicants and decisions, then connected them to the program.

  4. Testing

    Ran cases that should pass, cases that should fail, and cases with missing or odd input — then fixed what broke.

  5. Teamwork

    Reviewed the work with classmates and my teacher, and changed parts of it based on what they found confusing.

Loan Approval System

SLoan, my Class 12 board project: a desktop app written in Python with a MySQL back end.

The complete program is below. It uses CustomTkinter for the interface, with separate user and admin sections and loan pages for agricultural, educational and personal loans. The approval decision comes from a separate backend module that provides predict_loan_approval.

Accounts
Users register and log in. The admin has a separate login.
Admin dashboard
View every user, and add or delete accounts.
Three loan types
Agricultural, educational and personal loan forms that share one flow.
Approval prediction
Takes age, gender, salary, loan amount, tenure and CIBIL score, and shows the decision.
EMI analysis
Works out the monthly EMI at a fixed 7.5% interest and charts it against remaining income.
  • Python
  • CustomTkinter
  • MySQL
  • Pillow
  • Matplotlib
View on GitHub
  1. Install the packages. 
    pip install customtkinter pillow matplotlib mysql-connector-python
  2. Create the database. The app only needs one table for user accounts. 
    CREATE DATABASE sloan;
USE sloan;
CREATE TABLE user_credentials (
  name     VARCHAR(100),
  username VARCHAR(50) UNIQUE,
  password VARCHAR(100)
);
  3. Set the database password. The app connects as root on localhost and reads the password from an environment variable. 
    set SLOAN_DB_PASSWORD=your_password        (Windows cmd)
export SLOAN_DB_PASSWORD=your_password     (macOS / Linux)
  4. Add the predictor. Place a backend.py next to SLOAN.py that defines predict_loan_approval(age, gender, salary, loan_amount, tenure, cibil_score). Without it the loan pages show “Prediction unavailable”, though the EMI chart still works. An images/ folder is optional and only fills the side panels.
  5. Run it. 
    python SLOAN.py
